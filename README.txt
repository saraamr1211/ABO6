التشغيل:
1. فك الضغط.
2. افتح المجلد في VS Code.
3. افتح index.html بالمتصفح أو استخدم Live Server.
4. اتصال الإنترنت مطلوب لتحميل صور الألعاب والخطوط.

صور الألعاب:
تم تحديث روابط الصور إلى مصادر صور ألعاب معروفة، ومنها صفحة Steam الرسمية للعبة The Baby in Yellow (App ID 2291340). قد تمنع بعض الشبكات أو مستضيفات الصور العرض المباشر؛ إذا لم تظهر صورة معينة، نزّل صورة الغلاف من موقع اللعبة الرسمي واحفظها داخل المجلد ثم استبدل رابط src باسم الصورة المحلية.

رابط تيك توك:
في index.html ابحث عن YOUR_TIKTOK_LINK واستبدله برابط صفحتك الكامل، مثل https://www.tiktok.com/@yourname
